# Thundercar Host

This repository hosts the code for the host computer to see the robot visualization, etc.

# To configure for visualization:

Ensure that there gazebo package is installed
- sudo apt install ros-humble-gazebo-ros-pkgs 

# To compile
Head to host_amd/ and execute:
- colcon build

Tip: feel free to remove any build/ install/ log/ folder.
